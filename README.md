# ShootStar
A demo game.

当前 Gameplay 临时闭环：

- 从 `Assets/Scenes/MainMenu_Improved.unity` 启动；也可直接运行 `GamePlay` 场景。
- 故事模式：清理前两波普通敌人，击败第三波 Boss 后通关。Boss 波次沿用 Enemy Manager 的 `bossWaveNumber` 配置，当前为 3。
- 无尽模式：Boss 波次结束后继续下一波，直到玩家死亡。
- 暂停可继续、进入设置并返回本局，或返回主菜单。设置页提供本次运行的音乐和音效音量调整。
- 通关或死亡后，确认进入结算；达到前十可提交名字保存成绩，取消则跳过保存。
- 结算页可选择 `PLAY AGAIN` 重开当前模式，或返回主菜单。新一局重置分数、角色和波次。

编辑器验证应覆盖故事通关、无尽跨过 Boss 波次、失败结算、重开，以及暂停/设置/主菜单的往返。

## 肉鸽阶段①：清波改装闭环

参考 Steredenn 将战斗与战机改装分段：普通波清场后进入 `FIELD REFIT`，从三个随机改装中选一个，再进入下一波。故事最终 Boss 后直接通关，无尽 Boss 后继续提供改装。当前三波故事结构保持不变。

- 改装界面支持鼠标点击，以及现有 UI 输入的方向导航与 Submit 确认。
- 长按射击进入改装时，先松开射击／确认键，再重新点击或确认才能安装；按键释放本身不会选择卡片。
- 改装期间冻结战斗，显示本局已选次数及伤害、射速、最大生命倍率；Esc 不能跳过奖励。
- 确认后恢复战斗输入，需要重新按射击键开火。
- 改装由 Enemy Manager 自动创建的 `RunUpgradeController` 管理，直接运行 GamePlay 和从主菜单进入都无需额外挂接。

### 本阶段约束与规则

| 约束 | 实现规则 |
| --- | --- |
| 临时火力和局内改装 | `weaponPower` 保留原有道具、到期、受伤降档规则；改装作为独立属性层，不因这些变化丢失。 |
| 状态与时间 | 独立 `UpgradeSelection` 状态，停止旧子弹时间协程后冻结；确认后以正常时间恢复，不复原清波前的慢动作。 |
| 输入 | 关闭战斗动作表，切换 Dynamic Update，由现有 EventSystem 接管界面；选择锁防止双击重复安装。 |
| 属性生效 | 射速重新生成等待参数，移动/闪避读取当前改装；弹丸每次启用记录本次伤害倍率，导弹爆炸使用相同倍率。不修改预制体属性。 |
| 重开与保存 | 改装数据仅存在当前场景实例中；Retry 重载场景后清空，不写入排行榜或长期存档。 |
| 奖励池 | 同屏不重复、满级退出池；剩余永久改装不足三种时补入可重复的维修、导弹、能量补给。 |
| 碰撞死亡 | 保留现有撞机即死规则，本阶段不调整碰撞伤害和平衡。 |
| 原有模式 | 故事最终 Boss 直接结算；无尽模式继续清波改装；死亡沿用原结算流程。 |

### 初始改装池

数值为原型初值，均按基础属性加算，后续通过实玩调整。

| 改装 | 每级效果 | 上限 |
| --- | --- | --- |
| Heavy Caliber | 所有玩家弹丸伤害 +20%，含导弹爆炸 | 5 |
| Rapid Chamber | 主炮射速 +15%，含 Overdrive | 5 |
| Reinforced Hull | 基础最大生命 +20%，同时回复增加的生命值 | 5 |
| Efficient Roll | 基础闪避耗能 -15%，仍受 Overdrive 耗能倍率影响，向上取整 | 4 |
| Vector Thrusters | 移速 +10%，与 Overdrive 倍率叠加 | 4 |
| Combat Capacitor | 每次命中／击杀回能额外 +1，Overdrive 期间仍不能回能 | 4 |

备用补给：回复最大生命的 50%；获得 5 枚导弹；结束当前 Overdrive 并恢复 50 能量。它们是一次性补给，不增加改装等级。为支持补给，修复了导弹耗尽后补充仍无法发射的问题；掉落物也会在改装结束后继续追踪玩家。

## 肉鸽阶段②首条链路：主炮穿透 → 分裂

从 `Assets/Scenes/MainMenu_Improved.unity` 运行，在主菜单选择 **BUILD TEST → MAIN GUN**。普通 Story / Endless 的波次数量保持原有规则；两种新改装也进入它们的随机奖励池。

测试章节复用 GamePlay 场景，由独立 `BuildTest` 模式安排六波普通敌人（4、4、6、6、8、8 架）和第七波最终 Boss。前六波每波清场后各选一次改装，Boss 后直接结算。普通敌人按前后对齐的编队入场并定点射击，方便观察穿透和侧向弹；结算页 `PLAY AGAIN` 会重开同一个测试章节并清空改装。

| 改装 | 前置 | 效果和代价 |
| --- | --- | --- |
| PIERCING ROUNDS | 无 | 主炮每发最多命中两个不同敌人，对同一敌人的多个碰撞体只结算一次伤害；Overdrive 主炮同样生效。 |
| FORKED ROUNDS | 已装 PIERCING ROUNDS | 主炮第一次穿透命中时，向当前弹道两侧 ±25° 各发射一枚侧向弹，每枚伤害为母弹的 40%；主炮单发伤害降低 15%。 |

- 测试章节每次奖励都保证提供尚未取得的下一项链路改装：先穿透，选到后再提供分裂。玩家可选其他卡，未选的链路项会在后续奖励继续提供；不会强制安装。两项各限一次。
- 侧向弹是较小的金色弹道，穿透主炮使用青色拖尾；改装界面显示当前链路和实际主炮伤害倍率。
- 侧向弹不再次命中触发分裂的那架敌机，也不继承穿透或分裂；每发母弹最多分裂一次。全局最多同时存在 32 枚侧向弹，达到上限时抑制额外生成。
- 伤害和命中预算在每次发射时重建；复用对象时清理拖尾、尺寸、忽略碰撞和侧向弹计数。侧向弹使用现有直射弹池，不增加新预制体。
- 分裂减伤只影响主炮及其侧向弹；导弹保持原有直击和爆炸规则。Overdrive 追踪弹穿透第一架敌机后沿命中方向直飞，避免围绕已命中的目标盘旋。

建议按顺序体验：第一波选穿透 → 第二波观察前后敌机受击并选分裂 → 第三至六波观察侧向弹和构筑强度 → 击败最终 Boss → 重开确认链路归零。也可故意跳过链路卡，检查后续是否继续提供。

## 阶段②其余流派：导弹爆破与过载机动

`BUILD TEST` 现在先打开流派选择：**MAIN GUN / MISSILES / MANEUVER / BACK**。三种测试章节都提供六次清波奖励与第七波最终 Boss；每次奖励保证提供所选流派尚未获得的下一项。普通 Story / Endless 也包含全部升级，但不保证出现顺序。`PLAY AGAIN` 保持所选章节，重开清空改装和战斗资源。

| 流派 | 升级链 | 效果与代价 |
| --- | --- | --- |
| 导弹爆破 | WIDE WARHEAD | 爆炸范围 +50%，发射冷却 +25%；从取得该升级起，每次改装额外补给 2 枚导弹。 |
| 导弹爆破 | CHAIN DETONATION，前置 WIDE WARHEAD | 直击或主爆炸击杀最多引发 4 次次级爆炸，次级伤害为主爆炸的 60%、半径为主爆炸的 75%；次级击杀不再产生新爆炸。 |
| 导弹爆破 | WARHEAD RECLAIMER，前置 CHAIN DETONATION | 累计每 3 个导弹击杀返还 1 枚弹药，包含次级爆炸击杀；单次引爆最多返还 1 枚。超过返还上限的完整三杀组不结转，余数仍保留。 |
| 过载机动 | ROLL ACCELERATOR | 闪避结束后获得 2.5 秒主炮射速 +50%，包括 Overdrive；重复触发刷新时长。闪避耗能增加 20%，可由 Efficient Roll 抵消一部分。 |
| 过载机动 | KINETIC BATTERY，前置 ROLL ACCELERATOR | 闪避和 Overdrive 的实际耗能按 1:1 积累充能，最多 100；下一轮主炮齐射一次性消耗充能，每点增加 2% 伤害，最多 3 倍。松开射击键可保存充能，持续射击则不断消耗小额充能。 |
| 过载机动 | OVERDRIVE RELAY，前置 KINETIC BATTERY | 进入 Overdrive 额外获得 50 充能，正常退出时获得相同的 2.5 秒射速增益；Overdrive 期间仍然不能回复能量。 |

六项各限一次。弹丸在发射时保存伤害、爆炸范围和导弹改装状态；充能对同一轮主炮的所有弹丸生效，分裂弹继承母弹伤害，不再次消耗充能；导弹不消费主炮充能。射速增益按战斗时间流逝，暂停／改装期间不计时，场景重开清空充能、射速增益和弹药回收进度。

战斗顶部显示 `ROLL BOOST` 剩余秒数、`CHARGE` 充能、`AMMO RECOVERY` 三杀进度，以及最近一次导弹爆炸的次级爆炸数、击杀与返弹信息。改装页同时显示三条构筑状态，并显示各升级实际的前置名称。

建议验证：

- **MISSILES**：前三次奖励依次选择该流派升级，观察冷却变长、每次改装补弹、群体击杀触发次级爆炸，以及三杀返弹；空弹药补给后仍可发射。
- **MANEUVER**：前三次奖励依次选择该流派升级。闪避结束后观察射速增益；停止射击再闪避储能，随后开火检查整轮爆发；满能量开启 Overdrive，检查进入充能、持续耗能充能和退出增益。
- 三条流派可混合：例如穿透／分裂主炮可以接受充能，导弹爆破可帮助击杀回能，但不允许无限爆炸代数、无上限充能或单次引爆返还多枚弹药。

独立回归测试覆盖所有流派的前置和保底、代价、增益刷新与过期、充能封顶与单次消费、导弹碰撞去重、次级爆炸限制、返弹封顶及新局重置。实战强度和实体设备表现仍需手动体验调整。

## 阶段③首批：Binary Stars 遭遇测试章节

入口：**BUILD TEST → ENCOUNTERS → MAIN GUN / MISSILES / MANEUVER**。三条章节沿用各自升级保底、六次改装、第七波现有 Boss 和 PLAY AGAIN。基础 BUILD TEST 入口仍保留。

参考版本固定为 **Steredenn: Binary Stars**。本批替换此前自拟的摆动、循环聚散、S 形换位和护卫绕圈，采用连续实机中可核对的横向穿场行为：从右侧屏外进入，保持队形和高度连续向左飞过整屏，从左侧屏外离场。入场、过中线、离场属于同一条恒速路线，没有到站减速、玩家专属半场、横向钳制或回右侧撤离。

### 运行约束

- `EncounterChapter` 仅生成数据，不读取 Unity 随机状态、奖励或掉落状态。默认种子 **3103**，Enemy Manager 的 `encounterSeed` 可配置；三条遭遇章节共享相同的路线、入场时间和射击节奏。
